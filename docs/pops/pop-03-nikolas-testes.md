POP 03: Processo de Testes das Funcionalidades

Objetivo: Padronizar a realização de testes básicos no sistema para identificar possíveis erros antes das atualizações no repositório principal.

Responsável: Nikolas Eduardo da Silva (Analista de Testes).

Quando usar: Após o desenvolvimento de uma funcionalidade ou correção de erro.

Pré-requisitos: Ter o projeto atualizado e funcionando no ambiente de desenvolvimento.

Passo a passo:
1. Abrir o projeto no VS Code.
2. Executar o sistema no ambiente de testes.
3. Verificar se a funcionalidade desenvolvida está funcionando corretamente.
4. Identificar possíveis erros ou falhas.
5. Registrar problemas encontrados para correção.

Evidências esperadas: Registro de testes realizados e confirmação de funcionamento da funcionalidade.

Critérios de sucesso: Funcionalidade funcionando corretamente sem erros aparentes.

Referências utilizadas: Documentação Flutter. GitHub Docs.
