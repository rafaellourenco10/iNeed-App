# POP 06: Levantamento e Gerenciamento de Requisitos

* **Objetivo:** Padronizar o processo de coleta, análise, documentação e validação dos requisitos do sistema.

* **Responsável:** Analista de Requisitos e Equipe de Desenvolvimento.

Quando usar: No início do projeto ou durante solicitações de novas funcionalidades e melhorias no sistema.

Pré-requisitos: Reunião agendada com cliente ou equipe solicitante e ferramenta de documentação disponível.

Passo a passo:

Realizar reunião para levantamento das necessidades do cliente.
Identificar requisitos funcionais e não funcionais.
Documentar requisitos de forma clara e objetiva.
Validar requisitos com o cliente ou responsável pelo projeto.
Registrar requisitos na ferramenta de gerenciamento utilizada.
Atualizar backlog ou documentação do projeto conforme necessidade.
Encaminhar requisitos aprovados para a equipe de desenvolvimento.
Evidências esperadas: Documento de requisitos atualizado, backlog organizado e aprovação do cliente registrada.

Critérios de sucesso: Requisitos documentados corretamente, validados sem inconsistências e compreendidos pela equipe de desenvolvimento.

Referências utilizadas: Engenharia de Software – Ian Sommerville. Scrum Guide. Documentação UML.
