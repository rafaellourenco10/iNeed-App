# POP 02: Como abrir um Pull Request (PR)

* **Objetivo:** Estabelecer o fluxo correto para solicitar a mesclagem de código novo na branch principal.
* **Responsável:** Rafael (Desenvolvedor).
* **Quando usar:** Quando uma funcionalidade em uma branch paralela for concluída e testada.
* **Pré-requisitos:** Ter commits realizados e enviados (`git push`) para a branch remota.
* **Passo a passo:**
  1. Acesse o repositório iNeed-App no GitHub.
  2. Vá na aba "Pull requests" e clique em "New pull request".
  3. Selecione a `main` como base e a sua branch como comparada.
  4. Preencha o título e a descrição informando o que foi feito.
  5. Clique em "Create pull request".
* **Evidências esperadas:** PR aberto e visível na aba correspondente do GitHub com status "Open".
* **Critérios de sucesso:** PR criado sem conflitos de merge automáticos e com descrição clara do incremento.
* **Referências utilizadas:** GITHUB DOCS. About Pull Requests.
