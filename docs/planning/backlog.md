# Backlog do Produto - iNeed

Este documento descreve as funcionalidades do aplicativo iNeed, organizadas em pacotes de entrega com base no versionamento semântico (SemVer).

## 📦 Versão 1.0.0 (Meta para o Final do 3º Bimestre)
Esta é a versão de produção obrigatória para a avaliação do projeto, contendo o MVP (Produto Mínimo Viável) para que o fluxo principal funcione.

**Épico 1: Gestão de Usuários**
* `[Funcionalidade]` Cadastro e Login de Clientes.
* `[Funcionalidade]` Cadastro e Login de Prestadores de Serviço (PJ ou CLT).
* `[Funcionalidade]` Criação e edição do Perfil do Prestador (foto, biografia e área de atuação).

**Épico 2: Descoberta de Serviços**
* `[Funcionalidade]` Barra de pesquisa para localização de profissionais.
* `[Funcionalidade]` Filtros básicos de busca (por função e por preço/hora).
* `[Funcionalidade]` Visualização do perfil do prestador e sua disponibilidade.

**Épico 3: Conexão Cliente-Prestador**
* `[Funcionalidade]` Botão para o Cliente enviar uma proposta de serviço ao Prestador.
* `[Funcionalidade]` Área para o Prestador visualizar e aceitar/recusar propostas.

## 🚫 Fora do Escopo da Avaliação Final
As funcionalidades abaixo representam a visão de longo prazo do produto, mas **não** farão parte do escopo acadêmico deste ano:
* Integração com gateways de pagamento (Pix, Cartão de Crédito) direto pelo app.
* Verificação automática de antecedentes criminais via API externa.
* Sistema de chat em tempo real com envio de mídia e áudio.
* Implementação de validação de dados mais robusta no sistema.
