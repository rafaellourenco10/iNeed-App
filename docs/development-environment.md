# Ambiente de Desenvolvimento - iNeed

[cite_start]Para garantir que a equipe consiga reproduzir o ambiente localmente e executar o aplicativo, utilizamos a seguinte stack[cite: 246]:

* [cite_start]**Sistema Operacional:** Windows com integração ao Windows Subsystem for Linux (WSL)[cite: 248].
* [cite_start]**Editor/IDE:** Visual Studio Code[cite: 249].
* [cite_start]**Linguagens e Frameworks:** Dart e Flutter SDK[cite: 250].
* [cite_start]**Banco de Dados:** Supabase (PostgreSQL) para Nuvem[cite: 251].
* **Controle de Versão:** Git e GitHub.

## [cite_start]Instruções de Instalação e Execução [cite: 253, 254, 256]
1. Clone o repositório em sua máquina local:
   `git clone https://github.com/rafaellourenco10/iNeed-App.git`
2. Acesse a pasta do projeto:
   `cd iNeed-App`
3. Restaure as dependências do Flutter:
   `flutter pub get`
4. Execute o aplicativo no emulador ou dispositivo conectado:
   `flutter run`
