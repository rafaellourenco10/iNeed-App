## Documentação do Projeto
Sobre o Projeto
Aplicativo é desenvolvido para conectar usuários que precisam de um colaborador ou prestador de serviço com profissionais aptos a realizar demandas gerais — sejam elas matinais ou noturnas.
A plataforma oferece uma solução prática tanto para quem precisa de um serviço quanto para profissionais que buscam uma renda extra com mais visibilidade e simplicidade.

Interfaces do Sistema

Admin
Painel de controle geral da plataforma, responsável por:
- Controle e supervisão geral do sistema
- Suporte a defeitos e bugs reportados
- Administração de prestadores e clientes cadastrados
- Análise e acompanhamento do desenvolvimento do aplicativo

Cliente
Interface amigável e simplificada, pensada para facilitar a experiência do usuário final, com:
- Barra de pesquisa para localizar o profissional ideal
- Filtros por função, preço por hora e diárias
- Visualização clara de disponibilidade e avaliações dos prestadores

Prestador de Serviço
Área de cadastro e perfil profissional, onde o colaborador pode:
- Selecionar as áreas de atuação desejadas
- Incluir documentos de recomendação, como:

Experiência comprovada
Certificações
Licenças
Documentação validada

Receber propostas diretamente dos clientes

Objetivo
A real intenção do aplicativo é proporcionar maior visibilidade pública de forma simples e acessível, beneficiando dois públicos principais:
Para Clientes

- Encontrar profissionais freelancers disponíveis com rapidez
- Ter praticidade na contratação de serviços pontuais
- Contar com a confiabilidade garantida pela validação do aplicativo

Para Profissionais (PJ ou CLT)

- Cadastrar-se facilmente e expor seus serviços
- Receber propostas de tarefas diretamente dos clientes
- Obter uma renda extra com mais simplicidade e autonomia
